1. Principes

Le Système Documentaire V02 repose sur une hiérarchie de classement en 4 niveaux :

Système Documentaire V02 ├── Section 00 — Gouvernance documentaire (IDs 001–020) │ └── Lot « Contrats 2026 » │ └── Document « Contrat maintenance informatique 2026 » ├── Section 01 — Gouvernance Groupe et juridique (IDs 021–040) ├── Section 02 — Stratégie Groupe, pilotage et performance (IDs 041–060) └── Section 03 — Organisation Groupe (IDs 061–080)

Chaque document est ensuite qualifié transversalement (en plus de son classement) par :

Famille + Domaine + Processus + Entité + Pays + Site + Poste/Département

Ces qualifications servent au filtrage « Documents applicables à mon poste » (menu « Mes documents ») et aux périmètres d'application.

Règle de continuité des ID : chaque section couvre une plage d'IDs (Section 00 : 001–020, Section 01 : 021–040…). L'ID officiel est conservé dans document_code / reference — il n'est jamais régénéré par le système.

En plus de sa position dans l'arborescence, chaque document est décrit par des qualificatifs transversaux (indépendants du classement) :

Les autres qualificatifs (Domaine, Processus, Entité, Pays, Site, Poste/Département) sont gérés en base et via l'import du registre CSV (v02:import) ; leur saisie dans le formulaire de création est une évolution prévue.

4. Étape 1 — Préparer la structure (une fois, puis à la demande)

1Créer la Section (Espace)
Menu « Espaces » → bouton « Espace »
  • Nom = intitulé de la section (ex. « Section 00 — Gouvernance documentaire »)
  • Description et couleur (optionnelles)
  • Renommage possible ensuite (champ inline + crayon) ; suppression seulement si vide
2Créer le Lot (Dossier) dans la section
Menu « Espaces » → dans la carte de la section → « Nouveau dossier »
  • Un lot appartient à une section (ex. « Lot 00 — Contrats 2026 »)
  • Plusieurs dossiers par section possibles ; renommage et suppression (si vide) disponibles
3Vérifier les référentiels transversaux
Administration → Référentiels (permission admin requise)
  • Onglets : domaines, processus, postes, départements, directions, sites, entités, pays
  • Créer les valeurs manquantes (ex. domaine « Finances ») ; renommage et suppression (si non utilisé) disponibles
  • Vérifier les familles : Administration → Types & métadonnées (ex. POL, MAN, PRC…)

1Famille
Déjà saisie à la création (type documentaire) — modifiable via Admin → Types
2Domaine, Processus, Entité, Pays, Site, Poste/Département
État actuel
  • Valeurs gérées : Administration → Référentiels (création, renommage, suppression si non utilisé)
  • Affectation au document :
    • par import du registre CSV (php artisan v02:import) — crée sections, lots, familles et domaines automatiquement ; ou
    • directement en base (documents.domain_id, process_id, pivot document_referential pour les dimensions multi-valeurs)
  • Les dimensions de l'utilisateur (poste, département, direction, site, entité, pays) sont portées par son profil — elles servent au filtre « Mes documents »
Évolution recommandée : ajouter ces champs au formulaire de création/édition du document (sélecteurs de référentiels) pour une saisie 100 % UI.

7. Étape 4 — Cycle de vie du document

PhaseComment
Validation / approbationOnglet « Workflow » de la fiche document → démarrer un workflow (étapes : vérification puis approbation) ; rejet → retour brouillon avec motif obligatoire ; approbation finale → statut « Approuvé — applicable »
DiffusionOnglet « Partage » : partage interne (utilisateur/groupe, droit view/download/edit, expiration) ou lien externe (si activé, expiration obligatoire)
ApplicationMenu « Mes documents » : documents approuvés-applicables filtrés par les dimensions de l'utilisateur ; accusés de lecture si requis
RévisionNouvelle version (onglet Versions) ; relance d'un workflow ; obsolescence automatique de l'ancienne version applicable
Archivage / rétentionArchivage manuel, rétention configurable par type (commande planifiée), corbeille puis suppression définitive réservée et auditée

8. Raccourci — import du registre maître (CSV)

Pour initialiser le Système Documentaire V02 en masse (sections, lots, familles, domaines, statuts) :

php artisan v02:import registre.csv [--tenant=1] [--dry-run]

Colonnes : id;code;titre;section;lot;famille;version;statut;proprietaire;date_application;prochaine_revue;domaine;criticite

  • Crée automatiquement : espaces (sections), dossiers (lots), types (familles), référentiels (domaines)
  • Contrôles : id/code obligatoires et uniques, statut parmi les 7 valeurs V02
  • Rapport ligne par ligne (ok / erreurs)

9. Récapitulatif — chemin complet

Système Documentaire V02 ├── Section (Espace) ← Menu « Espaces » │ └── Lot (Dossier) ← Menu « Espaces » (dans la section) │ └── Document (Fichier + métadonnées) ← Menu « Documents » → « Importer » │ ├── Famille ← Type documentaire (formulaire de création) │ ├── Domaine ← Référentiel domain (Admin → Référentiels / import CSV) │ ├── Processus ← Référentiel process │ ├── Entité ← Référentiel entity │ ├── Pays ← Référentiel country │ ├── Site ← Référentiel site │ └── Poste / Département ← Référentiels job / department

→ Puis workflow (validation → approbation) → « Approuvé — applicable » → visible dans « Mes documents » selon les dimensions de l'utilisateur.
